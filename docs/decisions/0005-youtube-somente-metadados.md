# ADR 0005 — YouTube somente como link + metadados

- **Status**: aceito · **Data**: 2026-10-21

## Decisão
Reconhecer vídeos/playlists e salvar título/autor/miniatura via oEmbed oficial. Nenhuma extração
de áudio ou contorno de restrições. "Reproduzir" abre o conteúdo no YouTube.

## Consequências
Respeita os termos da plataforma; a arquitetura de providers permite uma fonte autorizada futura.
